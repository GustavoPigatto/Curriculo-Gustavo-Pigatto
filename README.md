# Currículo Web — Gustavo Pigatto

Projeto desenvolvido para a disciplina de Desenvolvimento Web, com o objetivo de criar um currículo online utilizando HTML, CSS e JavaScript.

A página apresenta minhas informações profissionais, formação acadêmica, experiências, habilidades e formas de contato em uma interface simples e responsiva.

## Tecnologias utilizadas

* HTML5 para a estrutura da página
* CSS3 para estilização e responsividade
* JavaScript para interações
* Git e GitHub para versionamento do projeto

## Funcionalidades

* Estruturação com elementos semânticos
* Layout adaptado para computadores e dispositivos móveis
* Navegação pelas seções do currículo
* Links para contato
* Interações desenvolvidas com JavaScript
* Cuidados básicos com acessibilidade

## Como executar

Clone o repositório:

```bash
git clone LINK_DO_REPOSITORIO
```

Depois, abra o arquivo `index.html` no navegador.

Também é possível executar o projeto utilizando a extensão Live Server no Visual Studio Code.
